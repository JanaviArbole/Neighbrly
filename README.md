# Neighbrly

**Community Discovery & Local Services Platform**

Neighbrly is a full-stack web application that helps residents discover local service providers, nearby facilities, and useful community information.

## Project Details

- **Course:** Full Stack Development
- **Course Code:** F0002
- **Frontend:** HTML, CSS, JavaScript, React
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **API Testing:** Postman
- **Deployment:** Render

## Core Features

- Community selection and discovery
- Local service provider directory
- Nearby facilities directory
- Search and category-based filtering
- User accounts and authentication
- Provider reviews and ratings
- Favourites and listing reports
- Administrator verification and moderation
